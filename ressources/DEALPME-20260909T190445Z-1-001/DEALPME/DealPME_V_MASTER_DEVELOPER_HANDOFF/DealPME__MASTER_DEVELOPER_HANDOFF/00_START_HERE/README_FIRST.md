# DealPME V3.1 — Definitive Developer Handoff

**Status:** canonical consolidated package  
**Purpose:** one source of truth for implementation, demonstration, QA and regression testing.  
**Supersedes:** prior V3 / V3.1 distribution ZIPs. Do not implement from an older bundle once this package is issued.

## Start in this order

1. Open `../OPEN_ME_REFERENCE_PORTAL.html` for visual navigation.
2. Read `QUICK_START_DEV.md`.
3. Read the platform baseline in `../01_SOURCE_BASIS/`.
4. Read `../03_DEVELOPER_GUIDES/02_DEVELOPER_IMPLEMENTATION_STANDARD.md` and `01_VDR_IMPLEMENTATION_GUIDE.md`.
5. Use PT-001 as the gold Pass Transmission + VDR implementation reference.
6. Use PT-002 to PT-012 as regression/variant cases.
7. Use the 24 service scenarios for service-level normal, remediation and control/failure paths.
8. Run/implement against the interaction registries and release gates before accepting a feature.

## Non-negotiable product rules

- No visible control without an interaction contract.
- No visible tab without substantive fixture content.
- No AI retrieval beyond the user's current authorization boundary.
- No security claim stronger than the implemented/evidenced control.
- Seller-supplied financial information must retain provenance and appropriate unaudited/declared labeling unless separately verified.
- DealLens is assistive and source-grounded; it does not silently grant access, certify, advise, transact or publish.
