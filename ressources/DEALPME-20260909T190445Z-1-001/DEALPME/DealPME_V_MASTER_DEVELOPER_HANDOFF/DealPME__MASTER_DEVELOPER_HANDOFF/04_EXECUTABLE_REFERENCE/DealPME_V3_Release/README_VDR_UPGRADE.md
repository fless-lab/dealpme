V3.1 adds a decision-oriented diligence architecture: document intelligence, permission-aware AI, Evidence Map, Issue Radar, Q&R workflow, Financial Tie-Out, version intelligence, Engagement Pulse, Audit and Clean Team.

## Developer rule
Do not implement the reference as a purely client-side security model. The fixture shows expected UX states; production authorization, RPS/T2 gates, document ACLs, Clean Team and AI retrieval filtering must all be server-side.
