# DealPME VDR Intelligence — Design System

- Direction: corporate modernism, high-density diligence, DealPME navy/white/green.
- Desktop: 3-column Documents view: taxonomy / viewer / DealLens.
- Top IA: Cockpit, Documents, DealLens IA, Q&R, Risques, Engagement, Audit, Accès.
- No unsupported certification/security claim in reference screens.
- No French Code de commerce references; use DealPME OHADA/Togo governance.
- Protection copy: deterrence, attribution, traceability — never absolute capture prevention.
- DealLens AI is permission-scoped and read-only by default.
