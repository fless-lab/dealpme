# Pass Transmission content completeness

A golden fixture must contain enough substance to test the actual product, not only the first viewport.

## Financials
P&L, balance sheet, cash flow, debt/cash/net debt, BFR, DSO/DPO/inventory days, revenue and EBITDA trends, concentration, recurring revenue, export and source labels.

## Transaction
Structure, seller expectation, debt/cash treatment, BFR convention, buyer profile, funding evidence expectation, ordered status path and controlled CTAs.

## Risks
At least six material/representative risks for a robust sample; each risk must link to evidence. Golden reference cases should target 8–12.

## Documents
A golden VDR should populate all required folders with multiple realistic synthetic documents. A row without a usable synthetic content object/file is not a complete test document.

## Q&R
Include answered, open and in-review threads. Link questions to documents. At least one question should test each material diligence family represented by the case.

## Access states
Model guest, verified/unqualified, qualified, admitted, NDA executed, authorized and revoked. Opening the VDR must lead to a different deterministic result for each material state.
