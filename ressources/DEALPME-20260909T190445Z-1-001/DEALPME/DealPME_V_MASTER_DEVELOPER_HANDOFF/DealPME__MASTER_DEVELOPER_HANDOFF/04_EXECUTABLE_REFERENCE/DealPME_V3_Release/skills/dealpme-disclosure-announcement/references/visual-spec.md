# Website announcement visual specification v3

## First viewport
1. DealPME product header and essential navigation.
2. Synthetic-demo strip when using test data.
3. Hero: case reference, concise opportunity headline, sector, geography, company age, transaction type and visible access tier.
4. Primary actions appropriate to the tier: save, request admission, execute NDA, request detailed access, or open VDR. Do not show inaccessible actions as enabled.
5. Immediate financial rail: latest revenue, EBITDA, margin, headcount, transaction perimeter and seller price only when T2 permits it.

## Detailed body
- Overview / activity / operating strengths.
- 5-year revenue and EBITDA trend with direct labels.
- Latest net income, net debt/leverage, working capital, recurring revenue, concentration and geographic mix.
- Evidence-quality indicators: synthetic/declared/verified/professional review.
- Transaction rationale and seller-support period.
- Key diligence risks and open items.
- VDR status, NDA state, documents available, Q&A state and controlled next action.

## Visual behavior
- Navy + white base, restrained indigo and semantic green.
- Use open sections, strong dividers and tables/rails; avoid turning every datum into a card.
- All displayed numbers carry year and unit/scale.
- Use direct labels and simple bars/lines; no 3D charts, gauges or decorative market widgets.
- T0/T1/T2 access tier must be visible above the fold.
- Synthetic status must be impossible to miss in test fixtures.
- Do not invent user counts, buyer counts, deal counts, ratings or platform-success statistics in a fixture visual.
