# Visual fidelity

Preserve the accepted DealPME design system: true white surfaces, pale blue-gray page background, deep navy content hierarchy, semantic green actions, restrained indigo navigation accent, fine technical borders and generous spacing.

The detail page should remain transaction-dense but readable. Tabs stay horizontal and scrollable on mobile. Tables may scroll horizontally inside their own container; the page itself must not overflow.

Do not add decorative badges, fake metrics or unrequested marketing blocks. A dev-mode control bar may appear only in the test version.
