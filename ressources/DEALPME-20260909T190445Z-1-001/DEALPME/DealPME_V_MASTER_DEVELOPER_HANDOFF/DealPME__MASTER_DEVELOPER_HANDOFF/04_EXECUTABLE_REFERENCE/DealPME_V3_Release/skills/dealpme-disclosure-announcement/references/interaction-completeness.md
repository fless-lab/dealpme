# Interaction completeness

For each visible control specify: control ID, surface, label, action, target, authorization gate, success state, blocked/error state and audit event.

A complete Pass Transmission authorized view contains populated financials, transaction workspace, structured risks, documents, Q&R and VDR access. If a surface is intentionally outside the current fixture, it must answer with an explicit `SCOPE_NOTICE` rather than a dead link.

The QA harness must be able to enumerate visible controls and prove every ID exists in the registry.
